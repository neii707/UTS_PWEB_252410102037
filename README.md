# 🎵 NeiiHeree Music App

Aplikasi web pemutar musik dan pengelolaan playlist interaktif yang dibangun menggunakan framework **Laravel** dan Blade Templating. Proyek ini disusun untuk memenuhi tugas **Ujian Tengah Semester (UTS) Pemrograman Web**.

## 📌 Fitur Utama

- **Authentication View**: Halaman login sederhana sebagai gerbang masuk aplikasi.
- **Interactive Dashboard**: Halaman utama antarmuka pemutar musik (Music Player Vibe) lengkap dengan kontrol pemutaran lagu dan greeting pengguna.
- **Kelola Playlist**: Halaman daftar lagu (*Recently Played*) yang terintegrasi dengan pemutar media interaktif.
- **User Profile**: Halaman profil pengguna yang menampilkan detail status akun dan informasi kontak.
